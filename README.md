# User Manager CLI (Python)

A simple and clean command-line application to manage users, built with Python using Object-Oriented Programming principles.

This project is designed as a practice project to demonstrate core Python skills such as:
- OOP
- Data structures
- Loops and conditions
- CLI interaction

---

## Features

- Add users
- Edit users
- Delete users
- Show statistics:
  - Average age
  - Oldest user
  - Youngest user
- Persistent storage using JSON
- Object-Oriented Design

---

## Technologies Used

- Python 3
- JSON for data persistence

---


## How to Run

1. Make sure Python 3 is installed
2. Clone the repository
3. Run the project:

```bash
python main.py
